# FernsehHeute.de 📺 — Blitzschnelles TV-Programm für Deutschland

> Offizielle Website: **[https://fernsehheute.de](https://fernsehheute.de)**

**FernsehHeute.de** ist ein modernes, datenschutzfreundliches und blitzschnelles Fernsehprogramm für Deutschland. Entwickelt mit **Astro SSG** und global bereitgestellt über das **Cloudflare Edge Network**.

---

## ✨ Features

- ⚡ **Ultra-Fast Performance**: Statisch generierte Seiten (SSG) mit sofortiger Ladezeit und minimalem Datenverbrauch.
- 📊 **AGF-Offizielle Rangliste**: TV-Sender sortiert nach den offiziellen Einschaltquoten und Marktanteilen der *AGF Videoforschung*.
- 🎯 **Hauptsender & Spartenkanäle**: Über 100+ TV-Sender inklusive Das Erste, ZDF, RTL, SAT.1, ProSieben, VOX, Kabel Eins, 3sat, ARTE, Sky und regionalen Dritten Programmen.
- 📅 **Heute & Morgen**: Vollständige Programmübersicht für heute Abend ab 17:00 Uhr, Prime Time 20:15 Uhr und Vorschau auf morgen.
- 🎬 **Genre-Hubs**: Eigene Übersichten für [Spielfilme](https://fernsehheute.de/film-heute-abend/), [Serien](https://fernsehheute.de/serien-heute-abend/) und [Sport](https://fernsehheute.de/sport-heute-abend/).
- 🔍 **Live-Filter & Suche**: Sofortige Sendersuche und Kategoriefilterung im Browser ohne Seiten-Reload.
- 🌙 **Dark & Light Mode**: Modernes, barrierefreies Design mit automatischer System-Anpassung.
- 🔴 **Direkte Livestreams**: Offizielle und legale Mediathek-Streams der Rundfunkanstalten (ARD Mediathek, ZDFmediathek, Joyn, RTL+).

---

## 🛠 Tech Stack

- **Framework**: [Astro](https://astro.build) (Static Site Generation / SSG)
- **Styling**: Tailwind CSS
- **Deployment**: [Cloudflare Pages](https://pages.cloudflare.com)
- **Data & Enrichment**: IPTV-EPG & TMDb (The Movie Database)
- **Ratings & Ordering**: AGF Videoforschung

---

## 🚀 Lokale Entwicklung

```bash
# Repository klonen
git clone https://github.com/rovelati/fernsehheute-astro.git
cd fernsehheute-astro

# Abhängigkeiten installieren
npm install

# Entwicklungsserver starten
npm run dev
```

Die Anwendung startet lokal unter `http://localhost:4321`.
